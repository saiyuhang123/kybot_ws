# ROS1 → ROS2 迁移计划：qwen_vision + robot_voice

## 概述

将 `src/qwen_vision` 和 `src/robot_voice` 两个 ROS1 catkin 工作空间迁移为 ROS2 Humble ament 包。涉及 4 个包的转换。

## 包结构决策

**当前结构**（嵌套 catkin workspace）：
```
src/qwen_vision/src/qwen_vision/     # Python 包
src/qwen_vision/src/usb_camera/      # C++ 包
src/robot_voice/src/robot_aiui/      # C++ 包
src/robot_voice/src/kybot_msgs/      # 接口包
```

**目标结构**（扁平化，符合 ROS2 惯例）：
```
src/qwen_vision/          # Python 包 (ament_python) — 合并原 qwen_vision 的脚本
src/usb_camera/           # C++ 包 (ament_cmake)
src/robot_aiui/           # C++ 包 (ament_cmake)
src/kybot_msgs/           # 接口包 (ament_cmake + rosidl)
```

> 删除中间的 `src/` 嵌套层，去掉 `.catkin_workspace` 文件和空的 `deth_image/` 目录。备份文件（`qwen_point_backup*.py`）不迁移。

### 3.4 Python 节点改造（rospy → rclpy）

**通用改动（所有 Python 节点）：**
- `import rospy` → `import rclpy` + `from rclpy.node import Node`
- 类继承 `rclpy.node.Node`
- `rospy.init_node(...)` → `super().__init__('node_name')` + `rclpy.init()`
- `rospy.Subscriber(topic, type, cb)` → `self.create_subscription(type, topic, cb, qos)`
- `rospy.Publisher(topic, type, queue_size=N, latch=True)` → `self.create_publisher(type, topic, qos)` (latch via QoS `DurabilityPolicy.TRANSIENT_LOCAL`)
- `rospy.Service(name, type, handler)` → `self.create_service(type, name, handler)`
- `rospy.get_param('~key', default)` → `self.declare_parameter('key', default)` + `self.get_parameter('key').value`
- `rospy.loginfo/warn/err` → `self.get_logger().info/warn/error`
- `rospy.spin()` → `rclpy.spin(self)`
- `rospy.Time.now()` → `self.get_clock().now()`
- `rospy.sleep(t)` → `time.sleep(t)` 或 `rclpy.clock.Clock().sleep_for(Duration(seconds=t))`
- `rospy.Rate(hz)` → `self.create_rate(hz)` 或 `rclpy.rate.Rate(hz)`
- `std_srvs/Trigger` → `from std_srvs.srv import Trigger`（ROS2 接口名相同）

**qwen_point.py 特殊改动：**
- `tf2_ros.Buffer` + `TransformListener`：ROS2 中 `Buffer()` 不传 `cache_time`，`TransformListener` 需要传 node
- `from tf2_geometry_msgs import do_transform_point` → ROS2 版本路径可能不同，需确认
- `threading.Thread(daemon=True).start()` 保留不变
- `queue_size=1` → QoS `reliability=RELIABLE, depth=1`

**qwen_vision.py 特殊改动：**
- 较简单，主要是 rospy API 替换

**test_vision.py 特殊改动：**
- `rospy.ServiceProxy` → `self.create_client(Trigger)` + `client.call_async()` 或同步等待
- `rospy.wait_for_service` → `client.wait_for_service()`
- `cv2.imshow/WaitKey` GUI 循环保留，但 `rospy.is_shutdown()` → `rclpy.ok()`
- `rospy.Rate(30)` → `self.create_rate(30)`
- `input()` 阻塞读取在 ROS2 中需要注意与 executor 的线程交互，建议放到独立线程

- `catkin` → `ament_cmake`

- `install(DIRECTORY AIUI/ DESTINATION share/${PROJECT_NAME}/AIUI)`

### 4.4 C++ 源码改造（roscpp → rclcpp）

**robot_aiui.cpp 改动：**
- `ros::init()` → `rclcpp::init()`
- `ros::NodeHandle nh_("~")` → 继承 `rclcpp::Node`，构造函数中 `this`
- `ros::Publisher` → `rclcpp::Publisher<T>::SharedPtr`
- `ros::Subscriber` → `rclcpp::Subscription<T>::SharedPtr`
- `ros::ServiceClient` → `rclcpp::Client<Srv>::SharedPtr`
- `nh_.advertise<T>(topic, qos)` → `this->create_publisher<T>(topic, qos)`
- `nh_.subscribe(topic, qos, cb)` → `this->create_subscription<T>(topic, qos, cb)`
- `nh_.serviceClient<Srv>(name)` → `this->create_client<Srv>(name)`
- `ros::spinOnce()` → 使用 `rclcpp::executors::SingleThreadedExecutor` 或 timer callback
- `ros::Rate(hz)` → `rclcpp::Rate(hz)`
- `ROS_INFO/WARN/ERROR` → `RCLCPP_INFO/WARN/ERROR(this->get_logger(), ...)`
- `XmlRpc::XmlRpcValue` → `this->declare_parameter()` + `this->get_parameter()`（YAML 嵌套结构用 `rclcpp::Parameter` 的 `as_parameter_map()` 处理）
- `$(find robot_aiui)/config/goals.yaml` → launch 中 `get_package_share_directory('robot_aiui')`

**agent_bridge.cpp 改动：**
- `extern` 函数签名中 `ros::Publisher&` → `rclcpp::Publisher<std_msgs::msg::String>::SharedPtr`
- `ros::Duration(0.3).sleep()` → `rclcpp::sleep_for(std::chrono::milliseconds(300))`
- `ros::spinOnce()` → 需要传入 node 指针或使用 executor
- libcurl 调用不变（纯 HTTP，不依赖 ROS）

**关键设计决策：**
- `DemoListener` 单例模式需要改为持有 `rclcpp::Node::SharedPtr`，因为 ROS2 API 需要 node 引用
- AIUI 回调线程中调用 ROS2 publisher 需要注意线程安全（ROS2 publisher 是线程安全的）
- `std::thread(...).detach()` 模式保留，但在回调中使用 `RCLCPP_*` 日志需要 node 指针

## 验证方案

1. **编译测试**：`colcon build --packages-select kybot_msgs usb_camera qwen_vision robot_aiui`
2. **接口检查**：`ros2 interface show kybot_msgs/msg/BoundingBox` 等确认接口生成正确
3. **节点启动测试**：
   - `ros2 launch qwen_vision qwen_vision.launch.py` — 确认节点启动、话题可见
   - `ros2 launch robot_aiui robot_aiui.launch.py` — 确认节点启动
4. **话题/服务检查**：`ros2 topic list` / `ros2 service list` 确认接口注册正确
5. **功能测试**：使用 `ros2 service call /locate_object_sync std_srvs/srv/Trigger` 测试视觉定位
