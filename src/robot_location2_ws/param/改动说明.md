# EKF + FastLIO 定位漂移修复说明

## 问题现象

冷启动时雷达定位正常，机器人**转圈后**二维雷达点云出现漂移。

## 根因

`transform_fusion.py` 发布的 `map→odom` 和 EKF 发布的 `odom→base_link` 基于**两个不同的 odom 坐标系定义**：

- **FastLIO** 的 odom：激光+IMU，通过 ICP 匹配全局地图得到 map→odom_FL
- **EKF** 的 odom：轮式里程计+IMU 积分，独立维护 odom→base_link

两个节点都叫 "odom"，但数值不同（传感器不同 → 各自的 odom 原点漂移分开了）。雷达点云经过混合 tf 链 `map→odom_FL → base_link_EKF` 时产生偏移。

## 修复方案

使 `map→odom` 与 EKF 的 odom 坐标系一致。核心公式：

```
T_map_to_odom = T_map_to_body @ inv(T_odom_to_body)
```

即：**FastLIO 提供的机器人全局位姿 - EKF 提供的局部里程计 = EKF 的 odom 原点在 map 中的位置**。

## 改动文件清单

### 1. `param/ekf_config.yaml`

| 参数 | 改前 | 改后 | 原因 |
|------|------|------|------|
| odom0 x, y | false | **true** | 增加轮式里程计绝对位姿参考 |
| odom0 yaw | false | **true** | 运动学模型提供朝向约束，不漂 |
| imu0 yaw | true | **false** | 陀螺积分朝向会无界漂移，去掉 |
| imu0_relative | true | **false** | yaw 已移除，不再需要相对模式 |

### 2. `param/velodyne_test.yaml`（FastLIO 定位配置）

| 参数 | 改前 | 改后 | 原因 |
|------|------|------|------|
| time_sync_en | false | **true** | 开启 IMU-LiDAR 时间同步，转圈时时间偏移严重 |
| freq_localization | 1.0 Hz | **5.0 Hz** | ICP 修正更频繁，不等漂大了再修 |
| localization_th | 0.9 | **0.5** | 降低匹配接受门槛，避免转圈时 ICP 被丢弃 |
| b_gyr_cov | 0.0001 | **0.001** | 加快 gyro bias 收敛 10 倍 |

### 3. `global_localization.py`（scan/odom 时间对齐）

- **原问题**：scan 和 odometry 在不同 ROS 回调中独立存储，时间不同步。转圈时 20ms 偏差 × 1rad/s = 1°+ 角度不匹配。
- **修复**：在 `cb_save_cur_scan` 回调中原子性地同时捕获 `cur_scan` 和 `cur_scan_odom`，确保 ICP 匹配时使用的 scan 和里程计来自同一时刻。

```python
# 修复前
def cb_save_cur_scan(self, msg):
    msg.header.stamp = self.get_clock().now().to_msg()  # 时间戳被覆盖
    self.cur_scan = pcd

# 修复后
def cb_save_cur_scan(self, msg):
    self.cur_scan = pcd
    self.cur_scan_odom = copy.deepcopy(self.cur_odom)  # 原子配对
```

### 4. `transform_fusion.py`（坐标系对齐）**← 核心修复**

- **原问题**：直接将 ICP 结果作为 `map→odom` 发布，但 ICP 结果在 FastLIO 的 odom 坐标系下，与 EKF 的 `odom→base_link` 不一致。
- **修复**：通过 tf 查询 EKF 的 `odom→base_link`，用公式 `T_map_to_odom = T_map_to_body @ inv(T_odom_ekf_to_body)` 计算与 EKF 一致的 `map→odom`。

```python
# 核心代码
T_map_to_body = T_map_to_odom_fl @ T_odom_fl_to_body      # FastLIO 全局位姿
ekf_tf = tf_buffer.lookup_transform('odom', 'base_link')   # EKF 局部里程计
T_map_to_odom = T_map_to_body @ np.linalg.inv(T_odom_ekf_to_body)  # 对齐
```

## 架构图

```
                         FastLIO 全局位姿
                      ┌──────────────────┐
                      │  T_map_to_body    │
                      │  (激光+ICP，准的)  │
                      └──────┬───────────┘
                             │
               ┌─────────────┼─────────────┐
               │             │             │
               ▼             │             ▼
      map ────────→ odom ────────→ base_link
               ▲                      ▲
               │                      │
      T_map_to_odom              EKF 发布
    = T_map_to_body          (轮式里程计+IMU)
    ⊕ inv(T_odom_EKF
          _to_body)

  map→odom 和 odom→base_link 基于同一个 odom 定义
  tf 链协调一致，雷达不歪
```
